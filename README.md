# 🐄 Dairy Tycoon

> An advanced incremental management and simulation game for Android, built entirely with Jetpack Compose.

**Dairy Tycoon** puts you in the shoes of an ambitious entrepreneur, tasking you with transforming a humble pasture into a ruthless global megacorp. Navigate complex supply chains, sabotage rivals with corporate warfare, dabble in anomalous genetic research, and execute hostile takeovers in your quest for market dominance.

## ✨ Key Features

*   **🏭 Deep Production & Supply Chain:** Manage raw milk extraction, factory bottlenecks, maintenance costs, and B2B auto-fulfillment quotas. 
*   **⚔️ Corporate Warfare:** Sabotage competitors, deploy cyber-attacks, and execute hostile takeovers by manipulating global market shares.
*   **🧪 Advanced Anomalous Research:** Push the boundaries of science with a sprawling Tech Tree. Unlock radioactive cooling, acoustic levitation, and genetic mutations.
*   **📈 Dynamic Economy Engine:** Deal with fluctuating stock valuations, unpredictable crisis events, and interest rates on corporate loans.
*   **📖 Narrative Story Engine:** Experience dynamic events guided by characters like Dr. A.W.E. and Barnaby through an integrated Inbox UI.
*   **📊 Comprehensive Analytics:** Track your operational efficiency, dividend payouts, and cyber-defense win rates in a beautifully designed dashboard.

## 🛠 Tech Stack & Architecture

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (100% declarative UI)
*   **Architecture:** MVVM (Model-View-ViewModel) with Unidirectional Data Flow (UDF)
*   **Concurrency:** Kotlin Coroutines & StateFlow
*   **Persistence:** Local File Storage & Gson Serialization

## 🚀 Getting Started

### Prerequisites
*   Android Studio (Iguana or newer recommended)
*   JDK 17

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/dairy-tycoon.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle and build the project.
4. Run the app on an Android emulator or a physical device.
